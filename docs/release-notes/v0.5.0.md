# v0.5.0 — automated releases

**This release ships no functional changes.** The cleaners, detectors, CLI flags, and API surface are identical to v0.4.0; `pip install --upgrade` gains you nothing but a version number. It exists to move release mechanics into CI and to prove that path end to end on a release where a failure costs nothing.

## Changed

- **The GitHub release is now created by CI** rather than by hand. Pushing a `v*` tag publishes to PyPI via Trusted Publishing, pushes the GHCR images, and then creates the GitHub release, gated on the PyPI upload succeeding so a release never announces an artifact that failed to ship. v0.4.0 shipped to PyPI while the releases page sat on v0.3.0; that gap is what this closes.
- **Release notes are curated, not generated.** CI reads `docs/release-notes/<tag>.md` — first line the title, the rest the body — and falls back to commit-generated notes only when the file is absent. The file must be merged before its tag is pushed.
- **Prerelease tags are handled explicitly.** Anything that is not a plain `vX.Y.Z` (`v1.2.3-rc1`, `v1.2.3b1`) publishes with `--prerelease --latest=false`, so a candidate never captures the "Latest" slot or moves the README release badge.
- **Re-running the release job is safe.** An existing release is edited rather than recreated, so a retry after a transient failure no longer fails on a duplicate.
- **`workflow_dispatch` removed from both release workflows.** Every step derives the version from the tag, so a branch dispatch could only ever fail the ref check. Tag push is the trigger.

## Documentation

- README carries PyPI version, downloads, and Python 3.10+ badges; the release badge is sorted by semver so it tracks the latest tag.
- CONTRIBUTING documents the release procedure, including the notes-before-tag ordering the automation depends on.

**Honesty contract:** deterministic cleaners report exactly what they removed. Rewrite, inpainting, spectral removal, and detector-evasion methods are labeled best-effort. Nothing here certifies that a vendor detector will fail.
