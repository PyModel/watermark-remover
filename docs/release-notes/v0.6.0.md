# v0.6.0 — terminal UI on pi-tui

The cleaners, detectors, and `wm` flags are the same as v0.5.0. What changed is `wm-tui`: one rendering path, a smaller first launch, and a prompt that can actually be edited.

## Changed

- **New rendering stack.** The terminal UI renders on `@earendil-works/pi-tui` 1.0.2 — a differential renderer with CSI 2026 synchronized output — instead of OpenTUI and Solid. The layout is an alternate-screen fullscreen view (header, list and detail, prompt, footer). The old stack is gone; there is no compatibility flag.
- **Smaller first-run install.** First launch no longer downloads ~500 packages. `wm-tui` runs `bun install --frozen-lockfile --production`, which installs 3 packages (pi-tui and its two libraries). A read-only wheel install is copied into the user cache first, so site-packages stays untouched.
- **Prompt editor.** The prompt is an editor with history, undo, and paste. `/command` and path autocomplete offer the command registry and files as you type. Up and down recall prompt history; they no longer move the file selection.
- **Key changes.** pageup and pagedown scroll the viewport. File selection is ctrl+k and ctrl+j. On quit the transcript is printed to scrollback, so the clean summary survives the exit.

## Fixed

- **Reveal highlights on emoji lines.** Mark offsets on the wire are Unicode code points. A non-BMP character (an emoji) before a hidden mark no longer shifts the highlight.

**Honesty contract:** deterministic cleaners report exactly what they removed. Rewrite, inpainting, spectral removal, and detector-evasion methods are labeled best-effort. Nothing here certifies that a vendor detector will fail.
