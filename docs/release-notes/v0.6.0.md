# v0.6.0 — terminal UI on pi-tui

`wm` keeps its CLI and batch workflow. This release replaces the terminal rendering stack, adds explicit single-file marking and user-configurable local models, and fixes format-cleaning and first-run installation regressions.

## Changed

- **New rendering stack.** The terminal UI renders on `@earendil-works/pi-tui` 1.0.2 — a differential renderer with CSI 2026 synchronized output — instead of OpenTUI and Solid. The layout is an alternate-screen fullscreen view (header, list and detail, prompt, footer). The old stack is gone; there is no compatibility flag.
- **Smaller first-run install.** First launch no longer downloads ~500 packages. `wm-tui` runs `bun install --frozen-lockfile --production`, which installs 3 packages (pi-tui and its two libraries). A read-only wheel install is copied into the user cache first, so site-packages stays untouched.
- **Prompt editor.** The prompt is an editor with history, undo, and paste. `/command` and path autocomplete offer the command registry and files as you type. Alt+up and Alt+down recall prompt history. While typing, arrows belong to cursor movement and completion.
- **Key changes.** Up/down navigate files when the prompt is empty; ctrl+k and ctrl+j remain aliases. Space marks exactly one file, replacing the previous mark or toggling it off. ctrl+r cleans only that marked file and refuses without a mark; Enter only submits the typed prompt. pageup and pagedown scroll the viewport. On quit the transcript is printed to scrollback, so the clean summary survives the exit.
- **Your own local model.** `/model` discovers local servers or lets you edit a loopback URL and model ID. Settings are saved per user; no fixed model, Pi model SDK, or cloud catalog.
- **Release gates.** Parallel Python/TUI checks feed independent cleaning and installed-wheel gates. Tag releases publish the verified artifacts without rebuilding them. A weekly dependency check runs without model credentials.

## Fixed

- **Reveal highlights on emoji lines.** Mark offsets on the wire are Unicode code points. A non-BMP character (an emoji) before a hidden mark no longer shifts the highlight.
- **Format cleaning.** TIFF SubIFD arrays and nested directory chains are scrubbed completely. HTML inspection and cleaning agree on nested/escaped JSON-LD provenance keys and comments outside raw-text regions. Comment action details carry the correct removal count. JSON-LD provenance keys are removed surgically (the block's payload survives), bare vendor words in comments, meta content, JSON-LD values and frontmatter values no longer trigger removal, and ODT/DOCX scrub template/user-defined/description provenance, dates and revision with inspect/clean symmetry. The saved local-model base URL is normalized to its origin so a pasted `.../v1` cannot double the route.
- **Frontend reliability.** Tab accepts visible autocomplete without changing the preset, file navigation keeps the focused row visible, and partial/stale frontend installs are retried. Packaging checks use isolated temporary storage and verify read-only installation staging.

**Honesty contract:** deterministic cleaners report exactly what they removed. Rewrite, inpainting, spectral removal, and detector-evasion methods are labeled best-effort. Nothing here certifies that a vendor detector will fail.
